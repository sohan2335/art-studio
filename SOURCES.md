# Sources and assets

- Requirements: user-supplied `GDGC-WebDev-Volunteer-Recruitement (1).pdf`, four pages. The brief's seed-data hyperlink points to the ZIP below.
- Official seed dataset: https://drive.google.com/file/d/1ltlMKcxjvnssicoTakv4vfrFWCu69C7u/view
- Reference video: https://drive.google.com/file/d/1mfpHvJkjWC82oY-Hb4yPxTlELx7a3Oqq/view

The seed JSON and 12 JPEGs come from the assignment dataset. The supplied studio password has been removed from the public seed file; fresh installs generate a password locally instead. Preserve the source dataset when evaluating its sample catalogue. The app does not infer asset licenses or claim the filenames accurately identify the artworks depicted. The video informs the dark teal/cream palette, glass navigation and spacious typography; no source code or video footage was copied into the app.

No paid fonts, stock subscriptions, APIs or cloud plans are used. The frontend uses browser/system fonts. The backend uses Node's standard modules and built-in SQLite driver. No npm runtime packages are required. Atelier is a demonstration name for this assignment.
